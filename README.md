# source-offers

Instance Labs keeps here, as release assets, the complete corresponding source for GPL/LGPL code it distributed, to fulfil written source offers:

- circuitjs1-4.1.5.1js-5a7071687782: the CircuitJS1 circuit simulator the portal serves: upstream source, our patch, build files and build scripts.
- occt-import-js-0.0.23-occt7.6.1-O3.il3: the OCCT import engine the portal serves now (build il3): source, patches and build scripts.
- occt-import-js-0.0.23-occt7.6.1: the earlier OCCT import engine build.
- freecad-web-v1.0.0-958007722: the FreeCAD-Web engine served by the portal's FreeCAD editor 2026-09-25 to 2026-10-25 (offer valid to 2029-10-25).
- freecad-web-v1.0.0-958007722-il-changes: our changes and the image build inputs for that FreeCAD-Web engine.
- workers-image-tigervnc-1.16.2: the TigerVNC x0vncserver built into the worker image.
- workers-image-tigervnc-1.16.2-build: the worker image's TigerVNC build stage.

Bytes exactly as hashed in each release's SHA256SUMS. Never edit an asset; add a new release instead.
